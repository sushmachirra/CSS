# Flexbox Pricing Table

A responsive pricing table using HTML and CSS Flexbox, media query.
## Features

- 💡 **Responsive Design** – Works on all screen sizes
- 🎨 **Clean UI** – Simple and modern pricing table
- ⚡ **Built with Flexbox** – Efficient layout management

## 📂 Project Structure

Flexbox-Pricing-Table/
│── index.html  # Main HTML file
│── styles.css  # Styling with CSS
└── README.md   # Project documentation

## 🛠 Technologies Used

- **HTML5** – Markup structure
- **CSS3** – Styling and layout with Flexbox
- **Google Fonts** – "Sono" font for modern typography

## 🖥 Setup & Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/Flexbox-Pricing-Table.git
   ```
2. Navigate to the project folder:
   ```sh
   cd Flexbox-Pricing-Table
   ```
3. Open `index.html` in your browser:
   ```sh
   open index.html
   ```

## 📱 Responsive Design

The pricing table is **mobile-friendly** and adjusts to different screen sizes using CSS media queries.
